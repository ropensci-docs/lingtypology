# SOUNDCOMPARISONS's Language identifiers

Language identifiers from SOUNDCOMPARISONS. This dataset is created for
[`soundcomparisons.feature`](https://docs.ropensci.org/lingtypology/reference/soundcomparisons.feature.md)
function.

## Usage

``` r
data(soundcomparisons)
```

## Format

An object of class `data.frame` with 556 rows and 3 columns.

## Details

\#' @format A data frame with 556 rows and 2 variables:

- LanguageName:

  SOUNDCOMPARISONS language identifier

- LanduageId:

  Language Id
