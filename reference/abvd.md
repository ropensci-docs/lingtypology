# ABVD's Language identifiers

Language identifiers from ABVD
(<https://abvd.eva.mpg.de/austronesian/>). This dataset is created for
[`abvd.feature`](https://docs.ropensci.org/lingtypology/reference/abvd.feature.md)
function.

## Usage

``` r
data(abvd)
```

## Format

A data frame with 1468 rows and 2 variables:

- id:

  language identifier

- glottocode:

  Glottocode
