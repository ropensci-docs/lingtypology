# Phoible glottolog - language correspondencies

Language correspondencies for Phoible (<https://phoible.org/>). This
dataset is created for
[`phoible.feature`](https://docs.ropensci.org/lingtypology/reference/phoible.feature.md)
function.

## Usage

``` r
data(phoible)
```

## Format

A data frame with 2185 rows and 2 variables:

- language:

  language

- Glottocode:

  Glottocode
