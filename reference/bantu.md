# BANTU's Language identifiers

Language identifiers from BANTU
(<https://abvd.eva.mpg.de/bantu/index.php>). This dataset is created for
[`bantu.feature`](https://docs.ropensci.org/lingtypology/reference/bantu.feature.md)
function.

## Usage

``` r
data(bantu)
```

## Format

A data frame with 430 rows and 2 variables:

- id:

  BANTU word id

- word:

  word
