# AUTOTYP's Language identifiers

Language identifiers from AUTOTYP v. 1.1.1
(<https://github.com/autotyp/autotyp-data/>). This dataset is created
for
[`autotyp.feature`](https://docs.ropensci.org/lingtypology/reference/autotyp.feature.md)
function.

## Usage

``` r
data(autotyp)
```

## Format

An object of class `data.frame` with 1342 rows and 3 columns.

## Details

\#' @format A data frame with 1342 rows and 3 variables:

- path:

  path to the dataset in autotyp repo

- variable:

  variable name

- file:

  topic name
