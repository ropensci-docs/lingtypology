# Download SOUNDCOMPARISONS data

This function downloads data from SOUNDCOMPARISONS and changes language
names to the names from lingtypology database. You need the internet
connection.

## Usage

``` r
soundcomparisons.feature(word)
```

## Arguments

- word:

  A character vector that define with a feature ids from
  SOUNDCOMPARISONS (e. g. "one", "sharp_fem", "near_neut",
  "on_the_left", " I_will_give", "write_ipv_sg", "your_pl_pl").
