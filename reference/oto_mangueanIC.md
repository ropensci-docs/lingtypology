# Oto-Manguean Inflectional Class Database Language identifiers

Language identifiers from Oto-Manguean Inflectional Class Database
(<https://oto-manguean.surrey.ac.uk/>). This dataset is created for
[`oto_mangueanIC.feature`](https://docs.ropensci.org/lingtypology/reference/oto_mangueanIC.feature.md)
function.

## Usage

``` r
data(oto_mangueanIC)
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 20
rows and 2 columns.

## Details

\#' @format A data frame with 20 rows and 2 variables:

- Language.name:

  Languaeg names from Oto-Manguean Inflectional Class Database

- language:

  Language names from Glottolog database
