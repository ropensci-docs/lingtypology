# Download Oto-Manguean Inflectional Class Database data

This function downloads data from Oto-Manguean Inflectional Class
Database (<https://oto-manguean.surrey.ac.uk/>) and creates a language
column with the names from lingtypology database. You need the internet
connection.

## Usage

``` r
oto_mangueanIC.feature()
```
