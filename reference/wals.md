# WALS's Language identifiers

Language identifiers from WALS (<https://wals.info/>). This dataset is
created for
[`wals.feature`](https://docs.ropensci.org/lingtypology/reference/wals.feature.md)
function.

## Usage

``` r
data(wals)
```

## Format

A data frame with 2678 rows and 2 variables:

- wals.code:

  WALS language identifier

- glottocode:

  Glottocode
