# Circassian villages in Russia

A dataset containes the list of the Circassian villages in Russia with
genealogical affiliation, coordinates and district names. Most data
collected during the fieldworks (2011–2018).

## Usage

``` r
data(circassian)
```

## Format

A data frame with 158 rows and 6 variables:

- longitude:

  longitude

- latitude:

  latitude

- village:

  name of the village

- district:

  names of the subjects of the Russian Federation: kbr —
  Kabardino–Balkar Republic, kch — Karachay–Cherkess Republic, kk —
  Krasnodar Krai, ra — Republic of Adygea, stv — Stavropol Krai

- dialect:

  names of the Circassian dialects

- language:

  according standard Circassian devision there are West Circassian and
  Kabardian languages
