# Download ValPaL data

This function downloads data from ValPal (https://valpal.info) and
changes language names to the names from lingtypology database. You need
the internet connection.

## Usage

``` r
valpal.feature(na.rm = FALSE)
```

## Arguments

- na.rm:

  Logical. If TRUE function removes all languages not available in
  lingtypology database. By default is FALSE.
