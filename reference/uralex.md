# UraLex's Language identifiers

Language identifiers from UraLex
(<https://github.com/lexibank/uralex/>). This dataset is created for
[`uralex.feature`](https://docs.ropensci.org/lingtypology/reference/uralex.feature.md)
function.

## Usage

``` r
data(uralex)
```

## Format

A data frame with 27 rows and 3 variables:

- uralex.name:

  language name from database

- glottocode:

  Glottocodes

- language:

  language from lingtypology
