# Download Vanuatu Voices data

This function downloads data from Vanuatu Voices
(<https://vanuatuvoices.clld.org/>). You need the internet connection.

## Usage

``` r
vanuatu.feature(features, na.rm = TRUE)
```

## Arguments

- features:

  A vector with parameters from Concepts
  (<https://vanuatuvoices.clld.org/parameters>))

- na.rm:

  Logical. If TRUE function removes all languages not available in
  lingtypology database. By default is TRUE.
